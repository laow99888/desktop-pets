# input 编码中转站

以 input AI 中转站 logo 为核心设计的像素风 Codex v2 动画桌宠。

## 设计

黑色像素终端机体以白色 input 几何标志作为胸口核心，青绿、琥珀和红色状态灯分别表现请求处理、排队与失败状态。

## Codex 安装

将 `pet.json` 和 `spritesheet.webp` 一起复制到：

```text
C:\Users\你的用户名\.codex\pets\input-terminal\
```

完全退出并重新打开 Codex 后，在宠物设置中启用 `input`。

图集为 Codex v2 `8×11`，每格 `192×208`，完整尺寸 `1536×2288`。
