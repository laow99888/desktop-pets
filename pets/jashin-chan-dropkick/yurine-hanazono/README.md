# 花园百合铃

基于《邪神与厨二病少女》中花园百合铃形象制作的 Codex v2 动画桌宠。

## 文件

- `pet.json`：宠物元数据
- `spritesheet.webp`：8×11 动画图集
- `preview.png`：PNG 预览图

## Codex 安装

将 `pet.json` 和 `spritesheet.webp` 一起复制到：

```text
C:\Users\你的用户名\.codex\pets\yurine-hanazono\
```

完全退出并重新打开 Codex 后，在宠物设置中启用“花园百合铃”。

## 图集规格

每个动画格为 `192×208` 像素，完整图集为 `1536×2288` 像素，包含 9 行标准动作和 16 个视线方向。

## 版本说明

本版保留百合铃的酒红长发、黑色小礼帽、白色眼罩与黑白哥特萝莉裙装。动作以克制、冷静和略带腹黑感的气质为主，不加入血腥武器或夸张魔法效果。
