# 美杜莎

基于《邪神与厨二病少女》中美杜莎形象制作的 Codex v2 动画桌宠。

## 文件

- `pet.json`：宠物元数据
- `spritesheet.webp`：8×11 动画图集
- `preview.png`：PNG 预览图

## Codex 安装

将 `pet.json` 和 `spritesheet.webp` 一起复制到：

```text
C:\Users\你的用户名\.codex\pets\medusa-jashinchan\
```

完全退出并重新打开 Codex 后，在宠物设置中启用“美杜莎”。

## 图集规格

每个动画格为 `192×208` 像素，完整图集为 `1536×2288` 像素，包含 9 行标准动作和 16 个视线方向。

## 版本说明

本版保留美杜莎的浅紫发、蛇形头饰与埃及风服饰，不使用遮脸纸袋。纸袋造型可作为后续独立变体制作。
