# 牛牛·米诺斯

基于《邪神与厨二病少女》中米诺斯形象制作的 Codex v2 动画桌宠。

## 文件

- `pet.json`：宠物元数据
- `spritesheet.webp`：8×11 动画图集
- `preview.png`：PNG 预览图

## Codex 安装

将 `pet.json` 和 `spritesheet.webp` 一起复制到：

```text
C:\Users\你的用户名\.codex\pets\minos-cowgirl\
```

完全退出并重新打开 Codex 后，在宠物设置中启用“牛牛·米诺斯”。

## 图集规格

每个动画格为 `192×208` 像素，完整图集为 `1536×2288` 像素，包含 9 行标准动作和 16 个视线方向。
